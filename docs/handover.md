## 一句话

NotesChain 是**单文件 Rust（Axum）后端 + 原生 JS 前端**的本地 Markdown 笔记工具：每天一个文件、勾选即回写、改完自动进 Git 版本链。产品规格见 [noteschain-prd-v05.md](noteschain-prd-v05.md)（含 v0.6 修订段），逐条实现状态见 [prd-audit.md](prd-audit.md)。

## 已完成

- 数据：三类目录 + 跨布局日记识别（路径优先/内容兜底）、图片双轨解析、BOM/CRLF 处理、`.trash` 回收站
- 待办：全局汇总、三级定位回写（抗外部插行）、完成标记剥离、`!p0`–`!p9` 优先级、排序/筛选、快速添加；首页勾选后**保持滚动位置**
- 日程：`## 日程` 解析、本日/本周/本月、进行中高亮、未识别行诊断、疑似日程可跳转；**新增日程用时间选择器**
- 标签：多级树（默认折叠、可排序、计数）、点击过滤；**frontmatter `tags` 并入统一索引**
- 搜索：子串 + 标签/状态过滤 + 仅看正文 + 上下文行 + 跳转定位；**标签页显示标签所在行**
- 编辑器：CodeMirror Live Preview，**编辑态正文向预览看齐**（h1 下边框 / h2 绿横杠 / 优先级徽标 / 完成项删除线 / 行内代码与代码块浅底）；**frontmatter 默认折叠成元数据卡片、双击露源码**；复选框、表格、图片预览、链接、悬浮预览、大纲；自动保存、冲突处理、默认预览模式；**标签 `#` 联想补全**
- 预览：可直接勾选待办（真实复选框，PATCH 回写）；双击正文进编辑、Ctrl+S 保存回预览；双链按开关显示、完成标记不再漏出
- 外观：设置界面可配置**字体 / 字号 / 主题**（跟随系统 / 浅色 / 深色），localStorage 持久化
- Git：自动 init、防抖提交（默认 5 分钟，`--commit-debounce`/`--commit-force` 可配）、历史/diff（**按文件折叠 + 增删着色**）、按文件回滚、`--no-git` 开关
- 安全：启动 token + Cookie；新增 `--no-token`（本地免鉴权，默认仍校验）
- 其他：文件树（默认折叠、打开定位）、新建笔记（模板/frontmatter/日期选择器）、双链 + 反向链接 + 出链、宽屏模式、单文件 3.6 MB
- 文档：新增 [docs/api.md](api.md) 全量接口文档
