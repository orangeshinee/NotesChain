## 3. Token 规格

### 3.1 现有 token：不动

`style.css:9-60` 的全部颜色、间距、圆角、字号、行高、字体变量保持原值。深浅两份覆盖（`style.css:62-107`）保持结构不变。

### 3.2 本轮新增 token

新增颜色必须同时写进 `:root`、`prefers-color-scheme: dark`、`[data-theme="dark"]` 三处，禁止在组件里写字面量。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--action-bg` | `var(--accent)` | `var(--accent)` | 主操作底色（实心） |
| `--action-fg` | `var(--bg)` | `var(--bg)` | 主操作文字。**用 `--bg` 而非 `#fff`**，两套主题下 `accent` 与 `bg` 都互为反差，对比度才稳，理由同 `.notice::before`（`style.css:420`） |
| `--action-bg-hover` | `color-mix(in srgb, var(--accent) 88%, var(--fg))` | 同式 | 主操作 hover |
| `--state-loading` | `var(--muted)` | 同 | 加载态专用，与错误态区分 |
| `--shadow-popover` | `rgba(40, 32, 18, .16)` | `rgba(0, 0, 0, .45)` | 收敛散落阴影。**命名不带 warm**，因为深色值是中性黑 |
| `--mask-scrim` | `rgba(30, 24, 16, .38)` | `rgba(0, 0, 0, .55)` | 收敛遮罩 |

> 表中「同式 / 同值」的项（如 `--action-fg`、`--action-bg-hover`、`--state-loading`）**无需在深色块里重复覆盖**，继承 `:root` 即可；写进三处只为保持结构对称，别当成硬性要求。硬编码字面量只存在于 `--shadow-popover` / `--mask-scrim` 的定义中，组件内不得再出现。

**允许的一致性修复**（不改变视觉方向，只兑现文件头「颜色只走 `:root`」的约定）：把 `.prio.p2` 的 `#8a6a00` / `#d9b45f`（`style.css:945-949`）、两处遮罩 `background`（`1201,1269`）与 **5 处** `box-shadow`（`231,1157,1209,1261,1281`）的硬编码 `rgba(30,24,16,…)` / `rgba(40,32,18,…)` 收进上述 token。深色下暖棕阴影压冷灰底会偏色，深色给中性黑。透明度各不相同的 5 处阴影用 `color-mix(in srgb, var(--shadow-popover) X%, transparent)` 派生，不新增 5 个 token。

### 3.3 动效 token

| Token | 值 | 说明 |
|---|---|---|
| `--dur-fast` | `160ms` | 折叠、hover、状态切换 |
| `--dur-state` | `200ms` | 行退出、提示出现 |
| `--ease-out` | `cubic-bezier(.25, 1, .5, 1)` | ease-out-quart 近似，替换现有 `ease` |

约束：**只动画化 `opacity` 与 `transform`**，禁止动画化 `height` / `margin` / `padding` / `top` / `left`；禁止回弹缓动。`prefers-reduced-motion` 全局兜底已在 `style.css:1313`，本轮不重复实现。

## 5. 范围 B：状态与反馈

### 5.1 [P0] Git 无备份提示常驻可见

**这是规格违背，优先级最高，改动最小。**

**先纠正 v1.0 的一处自相矛盾**：`app.js:1796` 取的 `#git` 就是 `index.html:15` 的 `.brand .git`，全应用只有这一个 Git 状态容器。v1.0 一边要求「状态区常驻一行小字」，一边禁止该元素承载这句话，却没定义新容器 —— 实施时无处安放。本版给出明确位置。

- `app.js:1811-1814` 目前把 `仓库根` / `仅本地版本历史，无远程备份` / `最近错误` 全部塞进 `box.title`。
- **新增常驻容器**：在 `index.html` 的 `.brand` 区块之后、`.quicknav` 之前插入独立一行（初始 `hidden`，由 `setGit()` 决定显隐）：
  ```html
  <div class="git-notice" id="git-notice" hidden>仅本地版本历史，无远程备份</div>
  ```
  样式：`--fs-meta` + `--faint`、`padding: 0 16px 8px`、`white-space: normal`、`line-height: 1.5`。**禁止** `white-space: nowrap` / `text-overflow: ellipsis` / `max-width` 截断。
- **显隐/文案随 git 状态**（修复「无版本历史却宣称仅本地版本历史」的误导）：`setGit()` 里当 `git.available` 为真才显示；`--no-git` / 未装 git 时隐藏（`#git` 自身已显示「版本历史已关闭 / 未检测到 git」）。
- **窄屏（860px 断点）**：侧栏为抽屉，该行随侧栏出现（打开抽屉可见），**不做额外顶栏常驻**。这是「侧栏内常驻（D4=A）」与「窄屏常驻」无法兼得时的取舍，按 **A** 接受。
- `.brand .git`（`style.css:177-185`）保持原样，继续只放提交时间等短状态；`box.title` 保留，只放仓库根、最近错误等次要详情。
- **位置错配已知**：PRD 6.1 写的是「顶部状态区」，实现把 Git 状态放在侧边栏 brand。**D4 = A**：本轮不搬动现有结构（改动面更大），改在侧边栏 brand 区新增常驻行满足「常驻可见」的硬要求；PRD 6.1 的措辞留到下次修订校正。
- 验收：**git 可用时**不 hover 可见；浅/深两套主题下对比度 ≥4.5:1；`tools/browser-probe.ps1` 用现有的 `Eval-Js` 加一条断言，检查 `#git-notice` 存在、`getBoundingClientRect()` 宽高非零、`getComputedStyle().visibility === 'visible'`，且 `textContent` 含「仅本地版本历史，无远程备份」。（`--no-git` / 无 git 时应为隐藏，另断言 `hidden`。）

### 5.2 保存状态四态：不只靠颜色

`.status` 现有 `dirty / saving / saved / conflict` 四态只换颜色（`style.css:492-496`），文案只有「有冲突」「保存失败」这类短语（`app.js:1148,1158,1165`）。

- 每态配固定文字 + 非颜色线索（形状或前缀符号），例如：`未保存` / `保存中…` / `已保存 HH:mm` / `有冲突：重新加载或强制覆盖`。
- 颜色仍用现有 `--warn-fg` / `--accent` / `--danger`，**不新增色相**。
- 状态槽位给 `min-width`，避免文案长短导致顶栏元素左右跳动。
- 冲突 bar（`style.css:1180-1191`）保留两个动作出口，文案要指向它们。

### 5.3 勾选反馈

`app.js:946` 现在是 `tr.remove()` 直接移除，用户会怀疑没点上。

- 移除前给 `tr` 加 `.removing` class，走 `--dur-state` 的 `opacity: 1 → 0` + `translateY(0 → -2px)` 过渡，禁止动画化 `height` / `margin`。
- **实现必须写清**：`transitionend` 只认 `propertyName === 'opacity'` 且 `event.target === tr`（`transform` 也会触发，避免 double-remove）；同时挂一个 `--dur-state + 50ms` 的 `setTimeout` 兜底，防止过渡被中断导致行永久残留。两者用同一个一次性 `done()` 守卫。
- `prefers-reduced-motion` 用 `matchMedia('(prefers-reduced-motion: reduce)').matches` 判定，命中则**同步** `remove()`，不进动画分支、不等计时器。
- `busy`（`.45`）、`failed`（删除线 + notice）两态保留（`style.css:908-909`）；失败 notice 文案补一句下一步（「重试或刷新」）。

### 5.4 空 / 加载 / 错误三态分离

`.empty-state`（`style.css:711-716`）目前被 `loadingState` 与 `errorState` 共用（`app.js:338-349`），三者长得几乎一样。

- 新增 `.state` 基类 + `--loading` / `--error` / `--empty` 修饰，**三态不得复用同一视觉**。
- loading：进度词或骨架，不用「出错了」同款居中大标题。
- error：`.notice` + 1 个「重试」动作。
- empty：保留现有语气（「没有未完成的待办，清静。」），补 **1 个主操作 + 1 句语法示例**；首次启动无文件时主操作为「新建今天的日记」。
- 三种自定义语法（`- [ ]` / `#标签` / `HH:mm`）至少在对应空状态里给一句示例，不做独立帮助页。

### 5.5 动效边界

只做状态变化动效：主操作 hover、表单展开、行退出、提示出现。全表不允许新增装饰性动画、滚动驱动效果、回弹缓动。现有 5 处 `transition`（折叠箭头 / `tag-open` / 侧边栏抽屉，均为 `ease`）统一换成 `--dur-fast` + `--ease-out`。
