# 人工验收清单（需在你自己的机器上跑）

这些步骤无法自动化（需要真实笔记目录、真实云桌面、真实 git 环境）。照着做一遍，把结果填进最后的表格，就能判定 MVP 是否达标签收。

> 前提：已经 `cargo build --release`，拿到 `target\release\noteschain.exe`。

## 第 0 步：先复制一份目录做试点（强烈建议）

真实目录先别直接上，复制一份：

```powershell
# 示例：把现有 Silver Bullet 目录复制到 D:\notes-trial
robocopy "D:\原笔记目录" "D:\notes-trial" /E /NFL /NDL
```

理由：第一次启动会自动 `git init` 并生成 `.gitignore`（若目录还不是仓库），还会按模板新建当天文件。试点目录里做，确认无害再换真目录。

## 第 0.5 步（推荐）：先跑只读体检，不动任何文件

```powershell
pwsh -File tools\verify-real-dir.ps1 -Path "D:\原笔记目录" -Out .\体检报告.md
```

这个脚本以 `--no-git` 启动，**不建仓库、不生成 .gitignore、不改任何文件**，只输出：识别到多少日记/普通笔记、待办数、标签数、`todo:` 迁移条数、同名冲突、扫描告警，末尾用逐个 SHA256 比对确认「已有文件一个字节都没变」。

先看这份报告，确认识别没问题，再进入第 1 步用 UI 实际操作。

## 第 1 步：启动并看识别结果

```powershell
.\noteschain.exe --dir D:\notes-trial --port 8080
```

终端会打印带 token 的地址。**记录**：文件数、未完成待办数。

- [ ] 首页待办数量与你的直觉相符（不是 0、不是把代码块里的 `- [ ]` 也算进来）
- [ ] 左栏文件树按年/月分组，当前月展开
- [ ] 标签树能展开到 2~3 级，计数大致合理
- [ ] 顶部 Git 状态显示「上次提交 / 尚无提交」

## 第 2 步：确认「不破坏已有文件」

```powershell
cd D:\notes-trial
git status --porcelain
```

- [ ] 变更里只有：`.gitignore`（新生成）、`.git/`（新仓库）、当天日记（若原来没有）
- [ ] **已有笔记一个都没被改写**（`git status` 里不应出现旧文件）

如果出现旧文件被改，立刻停下来，这是 P0 问题。

## 第 3 步：图片抽检（PRD 10.1）

各找 20 个引用，分别在浏览器里看是否显示：

- [ ] 相对文件自身的写法（如 `2026/10/` 里的 `![](../../assets/a.png)`）
- [ ] 相对 notes 根的写法（如 `![](assets/a.png)`）
- [ ] 两轨都能命中且指向不同文件时，**相对路径优先**

## 第 4 步：待办回写与抗漂移（PRD 3.2.3）

1. 在首页勾掉一条待办
   - [ ] 原文件那一行变成 `- [x] … ✅ 日期 时间`，其他行没动
   - [ ] 取消勾选能精确还原成 `- [ ]`
2. 抗漂移：用 VS Code 打开同一文件，在待办区**上方**插两行并保存；回页面刷新后再勾这条
   - [ ] 仍然改对行，插入的两行没被破坏
3. 造两条完全相同的待办，勾其中一条
   - [ ] 命中的是行号最近的那条

## 第 5 步：Git 自动提交（PRD 6）

1. 随便改一段文字，等 30 秒
   - [ ] `git log --oneline` 出现 `auto: YYYY-MM-DD HH:mm (N files)`
   - [ ] `git config user.name` 没有被改动（提交用的是你原有的身份，或临时 `NotesChain`）
2. 删掉某天的日记后想找回
   - [ ] `git log -- 2026/10/2026-10-01.md` 能找到该文件的提交
   - [ ] `git show <hash>` 能看回原文

## 第 6 步：无 git / 关闭 git 的降级（PRD 6.2、6.4）

```powershell
.\noteschain.exe --dir D:\notes-trial --port 8080 --no-git
```

- [ ] 顶部显示「版本历史已关闭」
- [ ] 笔记、待办、编辑、搜索全部照常
- [ ] 不报错、不阻断启动

再试一次真的没有 git：临时把 git 从 PATH 移除（或在一台没装 git 的机器上）
- [ ] 顶部显示「未检测到 git」

## 第 7 步：性能（PRD 8，在目标云桌面跑）

```powershell
node tools\gen-corpus.js D:\perf-notes
.\noteschain.exe --dir D:\perf-notes --port 8081
```

记录（对照 `docs/perf-report.md` 的测法）：

| 指标 | 标准 | 云桌面实测 |
| --- | --- | --- |
| 冷启动 | < 1 秒 | |
| 空载内存 | 参考 < 50 MB | |
| 待办汇总 | < 3 秒 | |
| 打开笔记 | < 200 ms | |

网络盘上再重复一次，单独记录（文件监听在网络盘可能失效，确认「刷新」按钮能兜住）。

## 第 8 步：安全抽检（PRD 9）

- [ ] 新开无痕窗口访问 `http://127.0.0.1:8080/`（不带 token）→ 401
- [ ] 访问 `/api/files/..%2f..%2fCargo.toml` → 400
- [ ] 不带 Cookie 直接请求 `/api/asset?path=assets/a.png` → 401
