## 五、已知偏差与风险

1. **本机沙箱无法验证应用内 git 提交**：`git init`、`git add`、防抖调度、错误上报都验证过；`git commit` 写 `.git` 被环境拒绝。需在普通用户终端复核一次。
2. **`/api/todos` 仍是 O(n)**：已加 `limit/offset`、`status`、`tag` 过滤与「显示全部」兜底；19 万条待办时实测 4.7s，规格内（约 4 千条）为 104ms。
6. **编码与行尾**：已处理 UTF-8 BOM 与 CRLF 保留（实测勾选待办后裸 LF 为 0）；GBK 老文件只提示不改写。
3. **索引常驻全文**：内存约为语料 1.5 倍。
4. **日程视图只有本地时间**：跨时区、全天、跨天日程明确不支持。
5. **`raw/` 同名裸名冲突**：已实现启动告警与裸名禁用（PRD 3.5.4），侧边栏顶部提示，路径形式照常可用。

## 六、已知实现陷阱（留给后来人）

1. **不要在隐藏的 CodeMirror 上 setValue**：预览态下若同步编辑器内容，CM 在 `display:none` 容器里会进入测量死循环导致页面卡死。预览因此保持只读；勾选待办请在编辑视图或首页进行。
2. **块级装饰只能来自 StateField**：`Decoration.replace({block:true})` 不能由 ViewPlugin 提供（会抛错并让整页装饰失效），表格渲染走 StateField。
3. **装饰区间必须有序且不重叠**：RangeSetBuilder 对乱序/重叠会抛错，构建时要排序并跳过重叠。
4. **换实现后会静默失效的交互**：搜索结果跳转曾依赖旧 HTML 的 `data-line`，改成编辑器后失效且无人发现——这类改动务必跑 `tools/browser-probe.ps1`。
